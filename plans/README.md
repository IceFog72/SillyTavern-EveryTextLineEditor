## Findings considered and not planned (yet)

- Lorebook entry/Full JSON saves write a stale whole-book snapshot (lost updates): `src/SourceManager.ts:1269-1290`. Real; MED confidence depending on SillyTavern's `loadWorldInfo` cloning. Candidate next plan.
- HistoryStore: `onupgradeneeded` deletes the `sources` store on every version bump (`src/HistoryStore.ts:23-28`). It also has no `onabort`/`onblocked`/`onversionchange` handling, and does check-then-act across two transactions in `commit()`. Fix before the next `DB.VERSION` bump.
- A failed save leaves SillyTavern's in-memory state already written, with no rollback (`src/EveryTextLineEditor.ts:2605-2614`).
- Smaller bugs:
  - Escape does not cancel a rename (`:2471`).
  - Branch-switch errors are unhandled (`:975-1005`).
  - A failed Monaco/Typo load promise is cached until page reload (`:102-172`).
  - Async races in Monaco spellchecker and diff setup (`:2085-2124`, `:2755`).
  - select2 teardown is missing in `clearSelectedSource`.
- Theme JSON is applied with `Object.assign(power_user, theme)` and no key whitelist (`src/SourceManager.ts:316`). The user is editing their own theme, so it is low risk. A whitelist would still stop a pasted theme from replacing `power_user.instruct` and similar.
- REJECTED: innerHTML XSS. Every `innerHTML` sink uses a static template, and labels go in through `textContent`.
- REJECTED: committed `dist/`. It is required because SillyTavern loads extensions straight from git.
- REJECTED for now: TypeScript 5.9 → 7.0. That is a new native compiler, a separate decision unrelated to the editor upgrades.

- Monaco ESM build. The AMD `min/` build used today has been unsupported upstream since 0.53. It still ships in 0.57, but it installs a global `require`/`define` on SillyTavern's page. Moving to ESM needs a bundling decision for `dist/vendor`.
- Monaco diff as the only diff view. `docs/Diff-Alignment-Problem.md` "Option 3". This would retire the fragile `.pce-line` marking and Prism scroll sync that plan 007 carries forward.
